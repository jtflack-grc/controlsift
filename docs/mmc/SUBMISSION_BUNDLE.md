# MMC Submission Bundle — ControlSift

Use this checklist when packaging the optional Mentor Me Collective capstone handoff.

## Links

- Public site: GitHub Pages (`docs/`)
- Capstone view: `/capstone/`
- Repository README
- Research report: `reports/RESEARCH_REPORT.md`
- Data Card / Model Card / Risk Register: `governance/`
- Protocol seal: `governance/PROTOCOL_SEAL.json`

## Evidence to attach

1. Dataset manifest hashes
2. Classical baseline metrics JSON
3. Gemma / QLoRA metrics JSON (when available)
4. Failure Lab cases
5. Figures under `reports/figures/`
6. Short reflection paragraph (what failed, what you would not trust)

## Reflection prompts

- What did fine-tuning change versus prompting?
- Where does the model still fail?
- Why synthetic evidence is not production proof
- How protocol lock protected research integrity
