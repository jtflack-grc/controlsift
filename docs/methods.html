ControlSift

    Controlled benchmark, explicit version boundary

    ControlSift is designed as a small independent research laboratory, not a demo chatbot. The method tests evidence-quality classification with committed receipts and bounded claims.

    Research question Can small-model approaches classify cybersecurity evidence quality, and what does prompting versus parameter-efficient fine-tuning show under controlled evaluation?

    Task

    Five-class evidence quality classification. Primary evaluation is the label; rationale is secondary.

    Dataset

    Train 1000Validation 200Test 200Challenge 100Seed 42
    • Deterministic synthetic generation Scenario families mutate into labeled variants. No employer or customer evidence enters the corpus.
    • Family-level split isolation All variants of one scenario family stay in exactly one split. Leakage fails CI.
    • Rule-derived labels + label audit Not fully human-annotated. Challenge: 100% structural audit + 20-case narrative spot-check.
    • Version boundary The hardened classical benchmark is v1.1.0. Completed Gemma experiments use v1.0.0. Within-version comparisons are controlled; cross-version scores are descriptive only.

    Completed model ladder

    1. B0Majority class · v1.1.0complete
    2. B1TF-IDF + logistic regression · v1.1.0complete
    3. B2Gemma 3 1B zero-shot · v1.0.0complete
    4. B3Gemma 3 1B few-shot · v1.0.0complete
    5. M4Gemma 3 1B + QLoRA · v1.0.0complete

    QLoRA defaults: 4-bit NF4, double quant, LoRA r=16 / alpha=16, max length 512. Target modules are resolved from the loaded Gemma architecture, not copied blindly.

    Within Gemma v1.0, few-shot produced the strongest test macro F1 (~0.137). QLoRA was ~0.083 and test label-parse success was ~0.435.

    Evaluation

    • Primary metric: macro F1 Also accuracy, macro precision/recall, per-class scores, confusion matrices, parse-success rate.
    • Deterministic inference + strict parser Ambiguous model output becomes UNPARSEABLE, never silently “fixed” into the gold label.
    • Uncertainty and slices Bootstrap intervals, McNemar for paired comparisons where appropriate, slices by domain / artifact / difficulty / failure tags.
    • Protocol seal Hypotheses, metric, prompt, and test hash were frozen before final claims. See the Protocol and Assurance pages.

    What this method refuses

    No live auditor product, no RAG over real evidence binders, no OCR pipeline, no tuning against a sealed test set, and no fabricated public metrics.
