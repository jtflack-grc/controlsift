ControlSift

    Controlled benchmark, frozen protocol

    ControlSift is designed as a small independent research laboratory, not a demo chatbot. The method exists to answer whether domain adaptation helps, with receipts.

    Research question Can parameter-efficient fine-tuning materially improve a small general-purpose language model’s ability to evaluate the sufficiency and relevance of cybersecurity control evidence?

    Task

    Five-class evidence quality classification. Primary evaluation is the label; rationale is secondary.

    SUFFICIENT PARTIAL INSUFFICIENT IRRELEVANT CONTRADICTORY

    Dataset

    Train 1000 Validation 200 Test 200 Challenge 100 Seed 42
    • Deterministic synthetic generation Scenario families mutate into labeled variants. No employer or customer evidence enters the corpus.
    • Family-level split isolation All variants of one scenario family stay in exactly one split. Leakage fails CI.
    • Rule-derived labels + label audit Not fully human-annotated. Challenge: 100% structural audit + 20-case narrative spot-check. Surface is compositional packets (v1.1), not raw binder prose.

    Model ladder

    1. B0Majority classshipped
    2. B1TF-IDF + logistic regressionshipped
    3. B2Gemma 3 1B zero-shotgpu
    4. B3Gemma 3 1B few-shotgpu
    5. M4Gemma 3 1B + QLoRAgpu

    QLoRA defaults: 4-bit NF4, double quant, LoRA r=16 / α=16, max length 512. Target modules are resolved from the loaded Gemma architecture, not copied blindly.

    Evaluation

    • Primary metric: macro F1 Also accuracy, macro precision/recall, per-class scores, confusion matrices, parse-success rate.
    • Deterministic inference + strict parser Ambiguous model output becomes UNPARSEABLE, never silently “fixed” into the gold label.
    • Uncertainty and slices Bootstrap intervals, McNemar for paired comparisons, slices by domain / artifact / difficulty / failure tags.
    • Protocol seal Hypotheses, metric, prompt, and test hash freeze before final claims. See the Protocol and Assurance pages.

    What this method refuses

    No live auditor product, no RAG over real evidence binders, no OCR pipeline, no tuning against the sealed test set, and no fabricated public metrics.
