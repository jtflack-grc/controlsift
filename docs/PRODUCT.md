# PRODUCT.md - ControlSift public research site

## Users
Recruiters, GRC practitioners, ML reviewers, and MMC evaluators - reading fast, often on dark displays.

## Mode
**Read** first (build understanding). Failure Lab is light **Operate**. Persuasion is secondary to clarity and receipts.

## Brand voice
Calm, clinical, no hype. Proof over paperwork. Negative findings welcome.

## Anti-references
- Purple / indigo gradients
- Cream / beige “tasteful AI” surfaces
- Glassmorphism + glow accents
- Pill chip eyebrows over hero headlines
- Inter / Roboto / Fraunces / Space Grotesk defaults
- Nested card stacks
- Fabricated metric decoration

## Surface
OLED-first: true black canvas (`#000`), soft off-white type, no chromatic glow.
