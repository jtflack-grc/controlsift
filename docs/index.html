    The problem

    GRC teams confuse artifacts with proof. A policy that requires MFA is not evidence MFA is enabled. An export showing a privileged user without MFA can contradict the control outright.

    What already improved the research

    • Gate 1 caught a shortcut An early generator let TF-IDF saturate at 1.0. Dataset v1.1 compositional packing brought test macro F1 to ~0.53 before protocol seal.
    • Classical residual errors are informative TF-IDF is weakest on SUFFICIENT / IRRELEVANT / PARTIAL compositional cues; CONTRADICTORY remains easier (~0.93 F1).
    • Research surface is disclosed v1.1 measures packet reading (substance pointer, SCOPE, ROW_DETAIL) — not naturalistic binder OCR. See Assurance.

    What still fails / is unfinished

    • Gemma and QLoRA numbers are not public yet Code and sealed protocol are ready; gated HF/Kaggle execution is the remaining critical path.
    • Schema-gaming risk A model that only learns packet fields can look strong without understanding audits — treat that as a limited win if it appears.
    • Hard boundaries remain Failure Lab cases spotlight coverage gaps, policy-only submissions, and contradictory configurations. Explore them directly.
