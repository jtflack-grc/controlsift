    Can a small AI tell real security proof from paperwork?

    ControlSift in 60 seconds

    You don't need to know what an LLM, QLoRA, or macro F1 means to follow the research.

    01

    The security problem

    A document can be relevant to a control without proving the control actually operated. Policies, screenshots, exports, and logs aren't equally strong evidence.

    02

    The experiment

    The project tests five evidence labels using a majority baseline, a classic word-based classifier, two prompted Gemma runs, and a fine-tuned Gemma run. The synthetic benchmark was hardened during the work, creating a v1.0/v1.1 boundary that's now explicitly disclosed.

    03

    What we can say now

    Within Gemma v1.0.0, few-shot beats zero-shot and QLoRA. On the hardened v1.1.0 benchmark, TF-IDF scores about 0.53 macro F1. A strict classical-vs-Gemma conclusion requires both sides on one dataset version.

    Jargon decoder

    Benchmark
    A fixed set of cases used like an exam so models can be compared under controlled conditions.
    TF-IDF + logistic regression
    A classic machine-learning approach that uses word patterns. It's cheap, fast, and isn't a language model.
    Gemma 3 1B
    A relatively small Google DeepMind language model with roughly one billion parameters.
    Zero-shot / few-shot
    Ask the model with no worked examples / give it a few examples before asking.
    QLoRA
    A memory-efficient way to fine-tune a language model without retraining all of its weights.
    Macro F1
    A 0–1 performance score that gives each of the five evidence labels equal weight. Higher is better; it isn't the same thing as accuracy.

    The honest headline

    Gemma v1.0.0 produced a clear internal result: few-shot prompting is stronger than zero-shot and QLoRA, while QLoRA also suffers poor label-parse reliability. The hardened v1.1.0 benchmark has a TF-IDF baseline around 0.53 macro F1. What ControlSift shouldn't claim yet is that TF-IDF definitively beats Gemma on the exact same sealed benchmark; a matching-version rerun is required for that conclusion.

    Research boundaries

    • Synthetic, not customer evidence. The benchmark is controlled research data, not a production audit binder.
    • Labels are rule-derived. They're structurally audited but aren't a large human-labeled gold standard.
    • Human judgment remains authoritative. ControlSift isn't an automated auditor or certification engine.
    • Dataset versions matter. Cross-version scores are published as research history, not disguised as a controlled model ranking.
