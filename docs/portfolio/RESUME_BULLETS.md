# Resume Bullets — ControlSift

- Designed a leakage-controlled synthetic benchmark (~1,500 cases, 5 classes) for cybersecurity evidence-quality classification, with deterministic generation, family-level splits, and automated integrity tests.
- Implemented and compared classical (TF-IDF+LR) and LLM baselines (Gemma 3 1B zero-/few-shot) against QLoRA adaptation under a sealed evaluation protocol using macro F1 with uncertainty estimates.
- Built a static research site (Failure Lab, results receipts, Responsible AI) that surfaces only machine-readable metrics and documents limitations / prohibited uses.
