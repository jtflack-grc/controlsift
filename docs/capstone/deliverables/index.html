    Run notebooks locally (Anaconda)

    GitHub Pages only displays notebooks. To execute cells, use the controlsift-mmc conda env: 

    conda activate controlsift-mmc
powershell -File scripts/start_mmc_jupyter.ps1

    After the repo is on GitHub, set github_slug in docs/data/repo.json to enable Colab / Binder links here.

    Regenerate

    conda activate controlsift-mmc
python -m mmc.labs.run_all
