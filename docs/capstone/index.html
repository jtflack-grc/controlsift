    Problem statement

    Cybersecurity teams must distinguish artifacts that substantively demonstrate control operation from evidence that is incomplete, irrelevant, stale, or contradictory.

    Research aim

    Investigate whether domain adaptation using QLoRA improves a small language model on this bounded task, with sealed evaluation and explicit failure analysis.

    Dataset

    ~1,500 synthetic cases; five classes; family-isolated splits; challenge set. See the Data Card.

    Model development

    Gemma 3 1B IT with QLoRA; classical and prompting baselines for comparison. GPU execution is the remaining critical path.

    Evaluation

    Macro F1, slices, statistics, challenge generalization, Failure Lab. Protocol and seal: Assurance · Protocol.

    Responsible innovation

    Public Assurance hub: Model Card, risk register, intended/prohibited use, limitations, human review.

    Reflection

    Gate 1 already forced a dataset harden pass when TF-IDF saturated. Negative Gemma findings will remain valid if adaptation underperforms.
