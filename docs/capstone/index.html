    One place to navigate the complete project: the problem, outside research, methods, model results, implementation, responsible-AI work, program alignment, report, slides, reflection, weekly work, and submission package.

    Plain-English project: ControlSift tests whether a small language model can distinguish strong cybersecurity control evidence from paperwork that is incomplete, irrelevant, or contradictory. The classic TF-IDF baseline won; the project keeps that negative AI result and explains why.
