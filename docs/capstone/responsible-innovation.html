ControlSift

    Responsible innovation

    Responsible AI practice is built into the project: documented data and model limits, sealed evaluation, and explicit boundaries on automation.

    Design choices

    • Public metrics from files only — LLM scores appear after experiments produce JSON artifacts.
    • Protocol lock — prompt and evaluation splits are frozen before final model claims.
    • Label provenance — rule-derived labels with documented audit coverage; not presented as full human gold.
    • Benchmark disclosure — compositional packet design and its limits are stated in the Data Card and Limitations.
    • Human oversight — intended use requires human review for any real-world evidence triage.
    • Negative findings — underperformance relative to baselines remains a valid outcome.
